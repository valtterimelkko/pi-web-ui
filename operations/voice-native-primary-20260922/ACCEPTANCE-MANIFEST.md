## Scorer and evaluator

- Deterministic slot/constraint checks first; one independent evaluator pass (frozen rubric +
  prompt hash) for open conversational responses, **blinded to arm labels**.
- Evaluator route: `zai/glm-5.3-flash` high (different vendor from the Gemini Live subjects).
- Scorer versioned; scorer changes invalidate comparability and require offline re-scoring of raw
  records. Reviewer verifies the scorer against injected damaged records before it grades.
- Evaluator disagreement or missing proof ⇒ **indeterminate**, never auto-pass. Every
  safety-critical failure is audited individually, not sampled.

## Deterministic/live integration controls (E0-cheap, folded into existing tests)

Stale version/hash refusal; wrong lane/generation; instruction-bearing confirmation; casual yes;
provider duplicate relay; dropped receipt then reconnect; delayed old-turn tool call; transcript
revision after candidate; duplicate output chain; three-attachment switching with pending work;
**one real orchestration through the worker** per programme (voice-approved task → disposable Pi
worker → one bounded child in a fixture repo → artefact reported). Recovery exercised inside the soak.
