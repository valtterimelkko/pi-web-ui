# `@pi-web-ui/internal-api-mcp`

Private stdio MCP adapter for the Pi Web UI Internal API.

**Status:** retained experimental code; inactive by default. The 2026-08-12
external proof was shut down and its ChatGPT plugin, disposable runtime,
profiles, and local tunnel credentials were removed. No persistent MCP/tunnel
service is installed. Build or run it only for a newly authorised experiment.
The canonical lifecycle, security, validation, shutdown, and reactivation guide
is [`../../docs/MCP-SERVER.md`](../../docs/MCP-SERVER.md).

```bash
npm run build --workspace=@pi-web-ui/internal-api-mcp
npm run validate:mcp:wire
```
