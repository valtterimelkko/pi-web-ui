## Design decisions

1. **Dual-form objective conditions** (raw + `applyGoalObjectiveTemplate(raw)`) over projection resolution — recorded in builders.ts and above. Caller objectives that already carry the pointer register once (no never-firing duplicate); `goalPaused` gets the same dual form so a raw-objective wait also settles on pause honestly.
2. **Restart-reconciled goal_end detected via the firing evidence** (`includes('interrupted by restart')`) — the client-visible carrier of the server's `interruptedByRestart` marker (firings expose only `conditionId/firedAt/eventType/evidence/reconciled`; the fixed evaluator string is the contract-shaped witness). The `runNeverStarted` reconciliation goal_end (C2, contract 1.57.0) is NOT remapped — it is not a restart and keeps the projection classification (see blind spots).
3. **`interrupted` joins the template retry set** (`failed | cancelled | interrupted`) — an interrupted follow-up was never delivered; retry-once is the safe recovery. The brief's terminal-failure list plus the root-cause T1 direction (`retry only on failed|cancelled|interrupted`) agree.
4. **`no_text` kept distinct from `command`** — H2's undiagnosed 29 Luna no-text runs must stay visible as their own class; only the handler-return marker promotes to `command`.

All pi-orch changes are behind the `spawn`/`wait`/`result` verbs; auto-detect and explicit-conditions paths are pinned unchanged by the pre-existing suites (46 wait-layer tests green).

## Residual risks / cannot see

- The restart-evidence marker is a server **string**, matched with `includes`. If the server rewords the evaluator's evidence, the mapping silently degrades to the old projection classification (fail-safe direction: a goal_failed on restart, never a false success). A structured `data` field on firings would remove the coupling; that is wire-visible and out of scope here.
- `no_text` remains a real class: the 29 undiagnosed Luna production runs stay visible and unexplained (H2/E1 watch list).
- The duplicate-template fix cannot bring back G5's lost 40 minutes (the parent's brief queued behind the arm turn) — that is I2's server-side drain fix, not this lane's.
- Live proof scale: 2 children, peak 2 concurrent turns — correctness evidence only; no lag/CPU claims are made from it.
