  symlinks — a symlinked extension is `unfingerprintable` and is **excluded

  impossible. The cached-path run used **byte-identical copies** (sha256
  table above proves they are exactly the deployed `b046a8a` code, read-only
  use, nothing written back); the symlink setup was run as the **positive
  control** (below), which the brief itself suggested as a candidate wrong
  setup.

## Design decisions / notes for the parent

- Copies instead of symlinks for the cached-path agent dir (rationale in
  §Provenance); the symlink setup was reused as the positive control.
- The worker on a 240 s task backgrounds the sleep (bash foreground limit) —
  deterministic subagent-task samples should keep sleeps ≤ ~90 s.
- Transcript projection note: during check 2 the `visible_full` projection
  lagged the session JSONL by tens of seconds while polled; the JSONLs (and a
  later projection read) both contain the wakes. Recorded as an observation
  only.
- Agent OS mirror: nothing to change (no contract bump, no new codes).
- Residual risks: the held-vanished-owner entry (bounded at 64 owners /
  32 lines / 64 KiB per owner) persists until the owner key returns, the
  bound evicts it, or the process exits — measured behaviour of the
  owner-approved B1.3s design, unchanged by this lane.
