## 6. Deviations and how they were handled

1. **One unauthorised OpenRouter child in smoke 1 (harness phase).** The pre-selection Gate 0 loop attempted a lane-B child (session `01a0ff3f-…`, model `openrouter/poolside/laguna-s-2.1:free` applied at 00:52:38Z): a free model ($0 by registry cost) via an unauthorised pay-as-you-go provider — a policy deviation found live and fixed in `13b7eec8` (loop filters enabled lanes); smoke 2 ran lane A only. The parent confirmed and reported it to the owner.
2. **Lane-B dispatch churn in the soak (19 refused attempts, no calls).** `HEAP_SOAK_LANES=A` was set on the launcher but a transient unit starts from the manager env, so the supervisor still weighted lane B (~29% of dispatch rolls). **Every attempt failed at model application — "No API key for openrouter/…" — because the credential scope (parent condition) had removed the key: zero OpenRouter network calls, $0, no child_created events, sessions rolled back server-side.** The heap verdict is unaffected (it comes from post-GC samples and the backbone lane only; lane B is recorded separately per the load model). Root cause fixed in `f0fef972` (`supervisorEnvPassthrough`), RED→GREEN; the running arm was deliberately NOT restarted mid-run (a supervisor restart would orphan-sweep live lane-A children).
3. **One non-resident registry entry** under the run's children cwd at end (report: "Sessions still registered on the server under this run's children cwd: 1", with 0 live AgentSession, 0 retained) — most likely one of the refused lane-B creates whose server-side commit raced the client-visible error. No effect on the retention verdict (retained deleted children: 0); noted as a residual.

## 7. Blind spots

- **One route only** (`zai/glm-5.3-flash`, thinking low): no OpenRouter/Command-Code lane exercised (authorisation), so the heap verdict covers the authorised production route, not mixed-provider fan-outs.
- **2 hours, not 24:** B1's 24 h evidence remains the long-window reference; this run answers the plan's bounded-run question.
- **Quota-shaped load:** normal 56 min → throttled 30 min → paused 32 min (zai 5 h window, resets 05:41Z). The last ~1 h ran quota-paused (sampler + WS client + admission probes only). Per-state slopes reported; the warm-up-hour slope (39.81 MB/h) is warm-up + highest-load confounded.
- **Placement OFF** (the harness's isolation model; production runs placement ON via its own tools anchor).
- **MemoryMax 8G admission arithmetic:** throttle threshold = 8192 − 512 − 8×512 = 5120 MiB < A1's 5789 MiB RSS-at-heap-cap, so admission could bind before the 4 GiB V8 cap at this cap — with lane A capped at 4 concurrent (assumed 7 was the old arithmetic) the observed peak heap was 361 MB and no `memory_pressure` refusals occurred after boot; not exercised to the cap by design.
- **The tsx loader fidelity gap** (documented in the harness README): the disposable child runs under `node --import tsx` while production runs plain `node` — constant overhead, not a growth source.
- **Lag proxy** is a CDP round-trip time, not in-process lag; the burst's lag numbers come from the server's own A2 telemetry (in-process), so the burst verdict does not rest on the proxy.
